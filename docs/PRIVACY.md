# 隐私说明

本 Skill 不含遥测、用户行为采集、远程日志、广告 SDK、私有服务器通信或主动项目上传。发布脚本不联网。开发期官方资料核验仅访问公开文档 URL；使用期联网由宿主根据通用技术词完成，不发送工程内容。

扫描仅在明确授权根内，敏感文件默认禁止读取；必要配置在内存静态解析，仅输出识别必需的技术与定位。报告中的凭据、私有 URL 和可识别密钥脱敏。原始文本不作为扫描报告输出。扫描 JSON、候选和审查报告仅按用户需求保存到本地，不默认批量创建。

本 Skill 不能决定或承诺宿主平台如何处理上下文。使用 WorkBuddy、Codex 或其他平台时，以其服务条款、权限和隐私政策为准。用户应在授权前确认所选目录与数据可供宿主处理。

清理：用户可删除本地候选、报告、备份和解压目录；工具不自动删除用户原文件。源码工程的虚构恶意测试样本不会进入发布包。
