# 评分说明

确定性规则版本 1.0.0。权重为完整性20、项目适配20、可执行性20、一致性10、安全10、测试交付10、上下文效率10。每项都有检查、权重、适用性、证据、扣分与建议。

完整性仅按适用主题检查，检测到数据库/ORM 时才加入数据访问；动作和模糊规则使用显式文案指标；一致性检查精确重复和冲突候选；安全检查凭据、危险操作及授权/隐私规则；验收检查测试证据及如实报告；效率按产品建议字节预算和格式检查。主题出现不意味着内容正确，脚本不认证语义。

无代码资料时适配分为 unverified，覆盖率80%，earned 是当前分母下得分，total 与 grade 为 null。reference_normalized_score 与 reference_grade 是参考归一化值，不能伪装全项评分。高风险阻止优秀等级，参考等级也限制为 E。全部资料可评分时才展示完整 total。

minimal/standard/enterprise 建议上限分别为 8/16/24 KiB，不是必须凑满的长度，亦非平台强制。有效指令链总量需按宿主加载机制另算。

脚本结果和智能体语义审查分别报告。可选 --rules 输入结构化规则，已确认的强制冲突会限制等级；自由文本冲突仅为候选。语义层检查技术版本、架构、命令目录、用户要求适用范围和隐含冲突。性能提升和真实编码效果需要独立对照实验，本次未执行，不提供提升百分比。
