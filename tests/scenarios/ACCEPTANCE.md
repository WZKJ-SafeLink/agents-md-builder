# 宿主场景验收

20 个场景定义见 scenarios.json。路由提示、生成、安全、评分等可由单元/CLI测试验证；完整宿主自然语言行为未实际回放。每次实机验收记录宿主版本、模型、权限、输入、产物、断言结果和原文件摘要。没有 Python、无联网、只读附件等需分别设置真实能力限制，不能仅通过文档存在就判定通过。

## SC-01 只有自然语言

输入：我想建立 Java 项目的 AI 研发规范，请生成 AGENTS.md。

前置：无工程文件；用户未给版本和数据库。

模式：CREATE；输出：候选规范及关键未知项

断言：未指定版本保持 unknown；不编造测试命令。禁止：擅自选数据库或架构。

宿主实测：未执行。
