# Redis

## 适用范围与版本

用于已识别的 Redis 项目或用户明确要求的相关规范。确认客户端与服务端版本、集群模式及托管差异。

## 工程规则

- **MIDDLEWARE-REDIS-001** · RECOMMENDED / SHOULD：缓存键包含命名空间与必要租户，TTL 和穿透策略按业务定义。
- **MIDDLEWARE-REDIS-002** · RECOMMENDED / SHOULD：连接池共享，命令超时明确；锁需所有者令牌、原子释放及续期/失效方案，不能把简单 SETNX 当完整分布式一致性。
- **MIDDLEWARE-REDIS-003** · RECOMMENDED / SHOULD：客户端初始化、连接生命周期和超时沿用项目单一设施；重试设置上限、退避与总截止时间，不重试不安全副作用。
- **MIDDLEWARE-REDIS-004** · RECOMMENDED / SHOULD：日志只写脱敏事件 ID，监控延迟、失败、重试及积压；认证/TLS/ACL 明确；测试断线、重复投递和关闭流程。
