# 测试

## 适用范围与版本

用于已识别的 测试 项目或用户明确要求的相关规范。推荐实践随项目工具版本与既有策略适配，不要求安装未存在的工具。

## 工程规则

- **ENGINEERING-TESTING-001** · RECOMMENDED / SHOULD：测试观察外部行为与错误边界，避免复述实现或只匹配文案。
- **ENGINEERING-TESTING-002** · RECOMMENDED / SHOULD：关键数据库/消息语义用实际组件集成测试；报告未执行的检查。

## 验证方式

以现有项目命令或差异检查验证上述行为；无法执行时标记未验证。

## 最小示例

```python
self.assertEqual(result.returncode, 0)
```

示例是最小片段或交互契约，不是完整项目；先替换为项目实际类型、接口和版本。
