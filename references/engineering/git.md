# Git

## 适用范围与版本

用于已识别的 Git 项目或用户明确要求的相关规范。推荐实践随项目工具版本与既有策略适配，不要求安装未存在的工具。

## 工程规则

- **ENGINEERING-GIT-001** · RECOMMENDED / SHOULD：保留用户未提交改动；未经明确授权不提交、推送、重置或清理。
- **ENGINEERING-GIT-002** · RECOMMENDED / SHOULD：提交范围可审查，秘密不入库；变更描述包含行为与验证。

## 验证方式

以现有项目命令或差异检查验证上述行为；无法执行时标记未验证。

## 最小示例

```text
review diff -> run relevant checks -> report
```

示例是最小片段或交互契约，不是完整项目；先替换为项目实际类型、接口和版本。

## 常见错误与禁止事项

不得把此参考的建议自动升级为企业强制标准；不要复制不匹配版本的 API，不要忽略上述错误边界或泄漏配置秘密。无项目证据时不得声称验证已经通过。
