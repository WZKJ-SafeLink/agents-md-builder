# API 设计

## 适用范围与版本

用于已识别的 API 设计 项目或用户明确要求的相关规范。推荐实践随项目工具版本与既有策略适配，不要求安装未存在的工具。

## 工程规则

- **ENGINEERING-API-DESIGN-001** · RECOMMENDED / SHOULD：HTTP 方法、状态、幂等和分页按接口语义定义。
- **ENGINEERING-API-DESIGN-002** · RECOMMENDED / SHOULD：输入校验、授权和错误响应各自验证，响应不暴露内部实体秘密。

## 验证方式

以现有项目命令或差异检查验证上述行为；无法执行时标记未验证。

## 最小示例

```http
GET /items?limit=20
```

示例是最小片段或交互契约，不是完整项目；先替换为项目实际类型、接口和版本。

## 常见错误与禁止事项

不得把此参考的建议自动升级为企业强制标准；不要复制不匹配版本的 API，不要忽略上述错误边界或泄漏配置秘密。无项目证据时不得声称验证已经通过。
