# Docker

## 适用范围与版本

用于已识别的 Docker 项目或用户明确要求的相关规范。推荐实践随项目工具版本与既有策略适配，不要求安装未存在的工具。

## 工程规则

- **ENGINEERING-DOCKER-001** · RECOMMENDED / SHOULD：只有项目实际部署容器时加载，保留镜像基线和构建阶段。
- **ENGINEERING-DOCKER-002** · RECOMMENDED / SHOULD：不将秘密写 ARG/镜像层，使用项目已有密钥机制；运行权限最小化。

## 验证方式

以现有项目命令或差异检查验证上述行为；无法执行时标记未验证。
