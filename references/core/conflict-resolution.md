# 冲突边界

自动确认：同 ID 异文、相交路径范围同 key 的互斥强制值、同动作的 MUST/MUST_NOT、明确依赖版本不一致。候选问题：重复文本、不同分类的偏好冲突、根模块范围不清、版本范围交叠未知。语义判断：自然语言隐含架构冲突、事务传播与调用链、企业规则适用性。

冲突报告包含类型、规则 ID、双方位置、范围、证据、严重度、状态、影响与方案。不包含原始秘密。技术、版本、命名、架构、ORM、事务、安全、根模块、用户与事实、企业与推荐各维度通过 key/category 表达；未提取为结构化规则的文本仅给候选，要求智能体进一步分析。

范围路径相离则不冲突；独立模块与父级默认策略差异只报告范围复核；父级明确禁止例外时仍需解决。不是所有版本差异都冲突，兼容范围由官方版本资料与依赖解析进一步确认。
