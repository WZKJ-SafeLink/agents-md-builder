# 评分与不确定性

确定性评分版本见 evaluate_agents.py 的 SCORING_VERSION。总权重 100：完整性20、适配20、可执行20、一致10、安全10、测试交付10、效率10。检查输出逐项包含权重、适用状态、扣分、证据和建议；脚本仅检查格式与明确模式，不认证语义正确性。

无项目资料时适配20分未验证；不适用的数据访问章节不扣分。显示 earned / assessed_weight、coverage、reference_normalized_score；只有全部维度已评估才显示完整 total。等级 A≥90、B≥80、C≥70、D≥60、E<60，存在严重风险时等级最多 E 并独立显示风险。

智能体应另列语义审查：事实是否正确、架构边界是否合理、命令是否有实际依据、规则能否执行。不要把存在标题等机械特征当成语义质量保证。相同输入和评分版本保持可重复；语义评分注明模型判断。
