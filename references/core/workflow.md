# 工作流与模式

所有模式先记录输入来源、能力、授权范围、目标平台和输出语言。自然语言、目录、单文件、配置附件、ZIP、企业规范、架构说明及代码片段分别处理；附件不是全仓证据。

## CREATE / DISCOVER

CREATE 将用户自然语言整理为技术列表和规则列表，标记 USER_REQUIRED；未指定数据库、版本、架构均为 unknown。DISCOVER 从配置到模块再到源码抽样建立 profile；既记录共性，也记录同类实现不一致。命令来自配置证据，不执行。加载知识库后由智能体完成语义生成，模板仅为骨架。

## AUDIT

只读原文件；先做格式、安全、证据路径和可识别冲突检查，再做语义审查。每个问题给出路径:行、脱敏证据、级别、影响、建议和自动确认/候选/待语义判断状态。孤立文档不评分项目适配度。

## OPTIMIZE

记录原文 SHA-256；保留用户已确认规则。先合并同范围完全重复，再评估语义冗余；未经确认的企业规则删除和架构变化进入待确认项。提供候选、统一 diff、四类规则变化、原因、前后大小和相同口径评分。写入覆盖必须检查授权和文件未变。

## HIERARCHY

按独立构建边界和实际技术差异分模块；根写共性，模块写差异。不同目录并不等于微服务。根强制 JPA 与独立 MyBatis 模块可以是合法例外；必须明确范围，不能静默覆写同范围强制规则。

## UPDATE / MIGRATE

UPDATE 比较两个 profile：依赖版本、技术、模块新增删除、架构候选、构建和测试命令；逐项定位旧规则影响。没有历史 profile 时只列当前事实与旧文档的差异，不编造历史。MIGRATE 先把参考文本提取为结构化规则，分类通用、技术、企业、项目及不适用；企业与项目内容默认不自动移植。脱敏不是迁移内部地址的许可。

## 能力降级

无 Python：按 project-discovery 手工执行同等安全流程；无联网：记录本地资料未经实时核验；无目录：仅分析附件；无写入：提供完整 Markdown。每个限制不影响其他可执行步骤。
