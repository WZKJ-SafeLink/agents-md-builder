# 使用示例

1. 帮我分析当前项目，并生成一份企业级 AGENTS.md，已有文件先保留。
2. 帮我检查这份 AGENTS.md，给出质量评分、覆盖率及优化建议。
3. 我的项目使用 Spring Boot、JPA 和 PostgreSQL，请参考适用的阿里巴巴 Java 实践建立 AI 研发规范；未知版本不要猜。
4. 帮我为前后端分离项目生成根目录和有实质差异的模块级 AGENTS.md。
5. 帮我优化当前 AGENTS.md，保留原有强制规范，删除同范围重复内容，先给候选和 diff。
6. 项目升级了 Spring Boot，比较旧新 profile，检查哪些已有规则需要调整。
7. 帮我补充 JPA 的 N+1、分页、事务和乐观锁验证要求，不更换现有 ORM。
8. 帮我统一 RocketMQ 消费端开发方式，先分析客户端版本、消息确认及已有幂等实现。
9. Generate an English AGENTS.md candidate based on this repository's actual configuration.
10. Audit my AI coding instructions without modifying the source file. Show unverified project assumptions.
11. 不联网，只使用本地资料审查这份规范，并标记未经实时核验的版本规则。
12. 参考另一个项目的规范，只迁移适合目标技术栈的通用规则，不复制内部地址或企业专属信息。
